M5Dial Music

Télécommande multimédia Bluetooth pour iPhone, Android et Windows. Sur iPhone, elle affiche aussi le titre, l'artiste et un arc de progression.

1. Installer le firmware

Branche le M5Dial en USB-C, puis clique sur le bouton et choisis son port série.

Ton navigateur ne gère pas Web Serial : utilise Chrome ou Edge sur ordinateur. La page doit être ouverte en HTTPS.

Port absent ? Débranche le M5Dial, maintiens le bouton BOOT (G0) de la StampS3, puis rebranche-le.

2. Appairer ton appareil

  • iPhone : Réglages → Bluetooth → M5Dial Music, puis accepte l'appairage. Commandes + titre, artiste et progression.
  • Android : Paramètres → Appareils connectés → Associer un appareil → M5Dial Music. Commandes seules.
  • Windows : Paramètres → Bluetooth et appareils → Ajouter un appareil → Bluetooth → M5Dial Music. Commandes seules.

Android et Windows ne transmettent pas les infos du morceau en Bluetooth : l'écran affiche alors « Connecté ».

3. Commandes

  • Tourner la molette : volume − / +
  • Appuyer sur la molette ou taper sur l'écran : lecture / pause
  • Maintenir la molette appuyée 2 s : éteindre (sur batterie)
  • Glisser vers la droite / la gauche : piste suivante / précédente
